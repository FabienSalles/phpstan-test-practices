# Rules and skills

Each rule enforces a practice that [FabienSalles/claude-marketplace](https://github.com/FabienSalles/claude-marketplace) also teaches to coding agents as Claude Code skills. This table maps every rule to the skill sections that state its practice, on the `main` branch of the marketplace. A rule whose practice no skill section states yet says so; no link is invented.

The links can break without any change in this repository, when a skill heading is renamed. `bin/check-skill-links.php` checks them every week (see [CONTRIBUTING](../CONTRIBUTING.md#skill-links)).
